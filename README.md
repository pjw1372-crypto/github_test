# 🏆 2026 단톡방 어워즈

카카오톡 단체방 대화 TXT를 올리면 4개 부문 수상자를 뽑아 연말 시상식처럼 한 명씩 발표하는 웹앱입니다.
친구들끼리 웃자고 만든 **가상의 유머 시상식**이며, 모든 분석은 **브라우저 안에서만** 이뤄집니다 (서버·DB·외부 API 없음).

| 순서 | 상 | 기준 |
| --- | --- | --- |
| 1 | 🎤 말 좀 해라 상 | 메시지 수가 가장 **적은** 사람 (오름차순) |
| 2 | 🎮 롤대남 상 | 롤·롤하자·게임하자·솔랭·듀오·랭크·칼바람·협곡 등 등장 횟수 |
| 3 | 💘 여미새 상 | 여자·여친·여자친구·소개팅·여사친 등 등장 횟수 |
| 4 | 🦅 일베 상 (대상) | 역대 대통령·주요 정치인 이름, 운지·응디 등 밈 표현 등장 횟수 |

## 실행

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # 파서·키워드 집계 테스트
npm run build    # 프로덕션 빌드 (정적 페이지)
```

## Vercel 배포

1. 이 저장소를 Vercel에 Import → Framework: **Next.js** 자동 감지 → Deploy
2. 환경 변수·DB 설정 필요 없음 (Hobby 무료 플랜으로 충분)

## 친구들과 공유하는 법

분석한 사람이 결과를 내보내면, 친구들은 TXT 없이 시상식을 볼 수 있습니다.

- **🔗 공유 링크**: 결과(순위·횟수·예시 최대 3개)를 압축해 URL `#` 뒤에 담습니다.
  `#` 뒷부분은 브라우저가 서버로 보내지 않으므로 Vercel 서버에도 남지 않습니다.
- **💾 결과 파일(.json)**: 친구가 첫 화면 업로드 칸에 올리면 바로 관람 가능.
- "채팅 예시 포함하기"를 끄면 순위·횟수만 공유됩니다. 대화 원본은 어떤 경우에도 공유되지 않습니다.

> 실시간 동기화(방장 화면을 모두가 함께 보기)는 아직 없습니다. 진행 상태(`어워즈 번호 + 단계`)를
> `src/components/AwardsApp.tsx`의 `view` 하나로 관리하므로, 나중에 이 값만 실시간 채널로 주고받으면 확장할 수 있습니다.

## 분석 규칙

- **지원 형식**: PC(Windows) `[이름] [오후 3:24] 내용`, Android `2026년 1월 5일 오후 3:24, 이름 : 내용`,
  iOS `2026. 1. 5. 오후 3:24, 이름 : 내용`(24시간 표기 포함). UTF-8/UTF-16/EUC-KR 자동 판별.
- 여러 줄 메시지는 하나로 합치고, 입장·퇴장·초대·가리기 등 시스템 알림은 제외합니다.
- **순위는 키워드 실제 등장 횟수 기준**: `롤 롤 롤` → 3회. 키워드 포함 메시지 수는 별도로 표시합니다.
- **중복 집계 방지**: 긴 표현을 먼저 매칭하고 그 구간을 소비합니다 (`여자친구` = 1회, `여자`로 또 세지 않음).
- **오탐 방지**: 단어 시작에서만 매칭(`참여자`, `컨트롤` 제외), 뒤에 붙는 음절 제한(`롤케이크`, `롤러코스터`, `롤모델` 제외),
  예외어(`운지법`, `듀오링고` 제외). 친구 이름과 겹칠 수 있는 애칭(`재명이` 등)은 사전에서 뺐습니다.
- 동점자는 공동 순위(1, 1, 3…), 키워드를 한 번도 안 쓴 사람은 후보 제외, 한 사람이 여러 상 수상 가능.
- 말 좀 해라 상: 메시지를 보낸 사람 + 입장/초대 기록은 있지만 한 마디도 안 한 사람(0개)이 후보이며,
  마지막 기록이 퇴장인 사람은 제외합니다. 사진·이모티콘 메시지도 메시지 수에 포함됩니다.
- **봇 제외**: 이름에 봇·bot·GPT·피에스·관상가양반 등이 들어간 참여자는 자동으로 분석에서 빠집니다.
  첫 화면의 "🤖 사람 아닌 참여자 빼기 → 수정"에서 누구든 직접 빼거나 다시 넣을 수 있습니다 (`src/lib/bots.ts`).
- 키워드 사전은 `src/lib/keywords.ts` 한 곳에서 수정할 수 있습니다.

## 구조

```
src/lib/parser.ts     카카오톡 TXT 파서
src/lib/keywords.ts   어워즈별 키워드 사전
src/lib/matcher.ts    키워드 매칭 (등장 횟수·경계·중복 처리)
src/lib/analyze.ts    참여자 통계, 순위, 채팅 예시 선정
src/lib/share.ts      공유 링크 / 결과 파일
src/components/       첫 화면, 시상식, 최종 결과 화면
public/samples/       가상 인물로 만든 테스트용 대화
```
